# 🎮 Kumanda (D-Pad) ve Dokunmatik Kontroller

## 📺 Android TV kumanda haritası

Tüm işlevler `▲ ▼ ◄ ►`, `OK` ve `Geri` ile yönetilir. Chromecast with Google TV kumandasında **Menü**, `CH+/CH-` ve `0-9` tuşları yoktur; uygulama hiçbir işlev için bu tuşları şart koşmaz (ekran üstü sanal numaratör ve kanal çekmecesi vardır). Menü ya da Yer imi tuşu olan kumandalarda bu tuşlar, aşağıdaki `OK` basılı tut kısayoluyla aynı işi yapar.

| Ekran | Tuş | İşlev |
| :--- | :--- | :--- |
| **Kanal ızgarası** | `OK` | Kanalı tam ekran açar |
| **Kanal ızgarası** | `OK` basılı tut | Odak üstteki büyük paneldeki **İzle** düğmesine gider (kanal özellikleri) |
| **Kanal ızgarası** | Üstteki panelde `▼` / `◄ ►` | Simge düğmeleri: Favori, Kilit, **Düzenle**, Gizle; odaklanınca adı açılır. Düzenle kanalın adını/numarasını bu cihazda değiştirir |
| **Kanal ızgarası** | `Geri` (panelden) | Odak, `OK` basılı tutulan karta döner |
| **Özel M3U** | `OK` / `Geri` | Klasörü (eklediğiniz listenin adı) açar / klasör listesine döner (çiplerdeyken) |
| **Tüm ekranlar** | `Geri` | Bir üst düzeye çıkar: Canlı TV'de listeden kategori çiplerine, çiplerden (ve diğer ekranlardan) yan menüye; yan menüdeyken uyarı görünürken ikinci `Geri` uygulamadan çıkar |
| **Oynatıcı** | `▲` / `▼` | Sonraki / önceki kanal |
| **Oynatıcı** | `◄` | Hızlı kanal çekmecesi |
| **Oynatıcı** | `►` | Bir sonraki akış kaynağı (Akış 1 → 2 → 3) |
| **Oynatıcı** | `OK` / dokunuş | Alt çubuğu (dock) açar; ekranın yalnızca ~%15'ini kaplar. Solda kanal ve program, ortada **oynatma düğmeleri** (önceki kanal, 15 sn geri, oynat/duraklat, canlıya dön, sonraki kanal; odak oynat/duraklatta başlar), sağda kanal listesi, favori, alternatif yayın ve **Seçenekler**. Düğmeler simgedir, odaktakinin adı çubuğun üstünde yazar. `OK` basmadan açılan çubukta (kanal değişince) üstte kısayol ipuçları görünür. **Seçenekler** çubuğun üstüne açılır: kalite, ses, altyazı, ölçek, gece modu, önceki kanal, küçük pencere, 2×2, kanal numarası, kanalı gizle, oynatıcıdan çık (`◄` veya `Geri` kapatır) |
| **Kanal ızgarası** | Kategori çipleri | Tümü, **Favoriler**, **Son izlenenler** ve kategoriler. Çipe `OK` basınca odak çipte kalır (başka kategoriye geçmek ya da `▼` ile listeye girmek tek tuş) |
| **Oynatıcı** | `0` | Önceki izlenen kanala dön |
| **Oynatıcı** | **Seçenekler → Kanal numarası** | Sanal numaratör (0-9) |
| **Rehber** | Programa `OK` | Yayındaysa kanalı açar; ileriyse hatırlatma ekler/kaldırır |
| **Favoriler** | `►` → `▲/▼` → `OK` | Kanalı tutar, taşır, bırakır |
| **Favoriler** | Üstteki liste düğmeleri | Liste seç / yeni / adını değiştir / sil |
| **Ayarlar** | `▲/▼`, `OK` | Satırları gezer ve değiştirir |

## 📱 Telefon ve tablet

| Hareket | İşlev |
| :--- | :--- |
| Kanala dokun | Kanalı açar |
| Kanala uzun bas | Seçenekler: favori, PIN kilidi, gizle, düzenle, TV'de oynat |
| Oynatıcıda dokun | Kontroller görünür/gizlenir |
| Oynatıcıda **çift dokun** | Duraklat / oynat |
| **Sol kenarda** dikey kaydır | Parlaklık |
| **Sağ kenarda** dikey kaydır | Ses |
| **Yatay** kaydır | Önceki / sonraki kanal |
| `⌄` (sol üst) | Oynatıcıyı küçült (mini oynatıcı; ses sürer) |
| Ana ekrana çık | Ayara göre otomatik PiP veya arka planda ses |

Hareketler *Ayarlar → Oynatma → Dokunma hareketleri* ile kapatılabilir.
